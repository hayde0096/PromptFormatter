# PromptFormatter

PromptFormatter 是一个用于格式化和美化提示词的网页工具，适用于 AI、ChatGPT、Midjourney 等场景。

## 功能
- 支持多种格式的提示词输入
- 一键美化和格式化输出
- 适用于 GitHub Pages 部署

## 使用方法
1. 打开 [GitHub Pages](https://your-github-pages-url) 页面。
2. 输入或粘贴你的提示词。
3. 点击格式化按钮，获取美化后的结果。

## 部署
将本项目代码推送到 GitHub 仓库，并在仓库设置中启用 GitHub Pages。
